## 五、官方 VecAdd 设备路径

官方输入：

```text

```

设备编译命令：

```bash

  --target=Ascend910B1 \
  --enable-hivm-compile \
  -o artifacts/kernel.o
```

项目 `Makefile` 中已提供：

## 六、设备端运行所需的额外条件

要进行官方 VecAdd 的完整上板验证，需要：

1. AscendNPU IR 1.1.0 对应的 CANN 9.0.0；
2. 与硬件匹配的 ops 包；
3. `hivmc`；
4. `ASCEND_HOME_PATH`；
5. Ascend 驱动；
6. Atlas A2、Atlas A3 或兼容硬件；
7. `/dev/davinci*` 等设备节点。

当前 WSL 内全部缺失或不可用：

```text
hivmc              missing
CANN               missing
ASCEND_HOME_PATH   unset
/dev/davinci*      missing
```

因此不建议在 WSL 中强行进行 NPU 上板运行。
