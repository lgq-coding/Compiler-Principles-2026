## 六、已完成的核心观察

### 6.1 HFusion 到 HIVM

主 Pipeline 中实际包含：

```text
convert-hfusion-to-hivm
convert-tensor-to-hivm
convert-to-hivm-op
```

该过程将高层结构化计算逐步转换到 HIVM Tile 级表示。

### 6.2 AIV 核类型推断

输入：

```text
vecadd.mlir
```

执行：

```bash
bishengir-opt vecadd.mlir \
  --hivm-infer-func-core-type \
  -o artifacts/vecadd_hivm-infer-func-core-type.mlir
```

输出增加：

```text
hivm.module_core_type<AIV>
hivm.func_core_type<AIV>
```

说明向量加法被识别为 AIV 向量核任务。

### 6.3 片上内存规划

执行：

```bash
bishengir-opt artifacts/vecadd_hivm-infer-func-core-type.mlir \
  --hivm-plan-memory \
  -o artifacts/vecadd_hivm_core_plan.mlir
```

主要变化：

```text
memref.alloc
  ->
hivm.hir.pointer_cast(0)
hivm.hir.pointer_cast(32)
hivm.hir.pointer_cast(0)
```

可以观察到：

- 片上 UB 缓冲区被映射为具体偏移；
- 第二路输入偏移为 `32`；
- 输出缓冲区复用偏移 `0`；
- 体现生命周期分析和片上内存复用。

### 6.4 自动同步插入

执行：

```bash
bishengir-opt artifacts/vecadd_hivm_core_plan.mlir \
  --hivm-inject-sync \
  -o artifacts/vecadd_hivm_sync.mlir
```

输出增加：

```text
hivm.hir.set_flag
hivm.hir.wait_flag
hivm.hir.pipe_barrier
```

同步关系：

```text
PIPE_MTE2 -> PIPE_V
PIPE_V -> PIPE_MTE3
PIPE_ALL
```

说明中端会根据数据依赖自动插入搬运、计算和写回之间的流水同步。

### 6.5 HIVM 到上游 Linalg

CPU 观察输入：

```text
vecadd_host_for_cpu.mlir
```

执行：

```bash
bishengir-opt vecadd_host_for_cpu.mlir \
  --execution-engine-convert-hivm-to-upstream \
  -o artifacts/vecadd_host_linalg.mlir
```

降低结果：

```text
hivm.hir.vadd
  ->
linalg.add
```

这是最直接的方言转换和 lowering 证据。

### 6.6 完整 lowering Pipeline

执行：

```bash
bishengir-opt vecadd_host_for_cpu.mlir \
  --lower-for-cpu-runner-pipeline='wrapper-name=main_wrapper' \
  -o artifacts/vecadd_host_cpu_pipeline.mlir
```

该 Pipeline 共 30 个 pass，覆盖：

```text
HIVM -> Linalg -> Bufferization -> Loops
     -> SCF/CF -> LLVM dialect
```

最终输出中出现：

```text
llvm.func
llvm.call
llvm.load
llvm.store
llvm.getelementptr
llvm.cond_br
```

完整 pass 列表见：

```text
artifacts/cpu_runner_pipeline.txt
```
