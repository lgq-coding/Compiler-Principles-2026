4. **6 组测试结果**：

5. **与 LLVM IR 路线的差异分析**：
语义绝对等价，但物理约束更强。LLVM IR 可直接使用 32 位比较指令，但手写 RISC-V 汇编时，体系结构禁止直接使用 `bgtw` 等伪指令。必须先通过 `sext.w` 将 32 位寄存器符号扩展至 64 位，随后再使用 `bgt/beq` 进行安全跳转，规避高位脏数据污染。

6. **遇到的问题及解决方式**：
- **链接器崩溃**：默认环境遭遇 `zmmul` 识别失败。**解决**：严格挂载 2.42 版本驱动。
- **32位跳转编译失败**：非法的 `bgtw` 导致汇编器拦截。**解决**：查阅体系结构文档，引入 `sext.w` 补丁。

7. **答辩强调内容建议**：
建议凸显我们的自动化验证闭环（`run_tests.sh`），以及针对 32 位符号扩展（`sext.w`）与 MLIR 片上内存复用（`pointer_cast`）的底层洞察。

\subsection{RISC-V 物理级映射与 ABI 契约实现}
手写汇编严格遵守了 RV64G 体系结构与 LP64D 约定：
\begin{itemize}
    \item \textbf{内存与栈帧防线}：函数序言阶段强制下压 \texttt{sp} 指针（64字节），遵循 16 字节对齐铁律，并妥善保护了返回地址 \texttt{ra} 与所有的 \texttt{s} 级被调用者保存寄存器。
    \item \textbf{数据位宽安全}：针对 SysY 的 32 位整数规范，所有算术运算强制使用字宽指令（\texttt{addw, mulw, remw}）。在进行条件分支验证前，严格调用 \texttt{sext.w} 进行符号扩展，规避了因高 32 位脏数据导致的跳转越界。
    \item \textbf{控制流图转换}：完美实现了 \texttt{break} 与 \texttt{continue} 逻辑，利用无条件跳转（\texttt{j}）与条件跳转（\texttt{beqz, bgt}）构建了高内聚的基本块（Basic Block）。
\end{itemize}

\subsection{QEMU 自动化验证闭环}

\section{进阶部分：AI 编译器 MLIR 中端处理过程探究（共同完成）}

\subsection{MLIR 多级方言架构与传统 LLVM IR 的边界对比}
在基础任务中，我们验证了传统的 LLVM IR 是一种单一层级的中间表示。这种扁平化设计在面对现代异构 AI 硬件时，极易丢失张量层面的高阶拓扑结构。为此，我们调研了基于 MLIR 生态构建的 AscendNPU IR。其核心架构解耦为多级方言（Dialect）：
\begin{itemize}
    \item \textbf{HFusion 方言}：高阶图层抽象，负责深度学习计算图的算子融合。
    \item \textbf{HIVM / Linalg 方言}：中端核心。将高阶张量解构为循环嵌套，执行循环分块（Tiling）。
    \item \textbf{HACC / LLVM 方言}：底层硅片映射层。针对硬件矩阵计算单元发射指令。
\end{itemize}

\subsection{VecAdd 算子的渐进式 Lowering 物理验证}
通过 \texttt{bishengir-opt} 核心工具链，我们对官方算子截获了以下关键物理降维证据：
\begin{enumerate}
    \item \textbf{核类型推断}：经 \texttt{--hivm-infer-func-core-type} 分析，原生 \texttt{vecadd} 被打上 \texttt{hivm.func\_core\_type<AIV>} 标签，精准匹配 NPU 向量计算单元。
    \item \textbf{片上内存复用}：执行 \texttt{--hivm-plan-memory} 优化后，高级分配指令 \texttt{memref.alloc} 降级为物理内存偏移指针 \texttt{pointer\_cast(0)} 与 \texttt{pointer\_cast(32)}，实现了片上 UB 缓冲区的复用。
    \item \textbf{流水线屏障自动注入}：通过 \texttt{--hivm-inject-sync}，编译器自动推导出 \texttt{PIPE\_MTE2 -> PIPE\_V -> PIPE\_MTE3} 的依赖，利用 \texttt{set\_flag} 与 \texttt{wait\_flag} 确保了数据一致性。
\end{enumerate}
本次实验证实了 MLIR 通过“逐层剥离业务语义，逐步暴漏硬件约束”的思想，解决了单一 LLVM IR 无法兼顾高阶图优化与底层寄存器压榨的难题。
