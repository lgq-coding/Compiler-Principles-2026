### 输入输出约定

程序从标准输入读取一个整数 `n`，依次输出三行：

1. 第一行：`sum`，循环中满足给定条件的整数累加结果。
2. 第二行：`mixed`，使用 `+`、`-`、`*`、`/`、`%` 计算的混合表达式。
3. 第三行：`g`，`gcd(n + 3, n * 2 + 1)` 的结果。

## 四、程序控制逻辑

### 4.1 `is_even`

```text
x % 2 == 0 时返回 1，否则返回 0。
```

### 4.2 `gcd`

使用循环实现欧几里得算法：

```text
while (b != 0) {
    t = a % b;
    a = b;
    b = t;
}
return a;
```

### 4.3 `main`

1. 读取 `n`。
2. 令 `i = 1`、`sum = 0`。
3. 当 `i <= n` 时循环。
4. `i == 4` 时先将 `i` 加一，然后执行 `continue`。
5. `i == 6` 时执行 `break`。
6. 当 `i > 0 && is_even(i)` 成立时，将 `i` 加入 `sum`。
7. 计算 `x = n + 3`、`y = n * 2 + 1`。
8. 计算 `mixed = (x + y) * 2 - x / 2 + y % 3`。
9. 计算 `g = gcd(x, y)`。
10. 输出 `sum`、`mixed`、`g`。

## 五、LLVM IR 设计

LLVM IR 文件：

```text
sysy_demo.ll
```

主要约定：

```llvm
target triple = "riscv64-unknown-elf"

declare i32 @getint()
declare void @putint(i32)
declare void @putch(i32)
```

`is_even` 使用：

```llvm
%remainder = srem i32 %x, 2
%is.zero = icmp eq i32 %remainder, 0
br i1 %is.zero, label %even, label %odd
```

`gcd` 使用 `alloca`、`load`、`store` 和 `srem`，以较直观的方式表达源程序中的可变变量。

`main` 显式实现了：

- `while` 条件块和循环体块；
- `continue` 跳转；
- `break` 跳出；
- 逻辑与的短路求值；
- 函数调用；
- 算术和比较运算。

逻辑与：

```c
i > 0 && is_even(i)
```

在 IR 中先判断 `i > 0`。只有当该条件为真时，才调用 `is_even`，因此保持了 `&&` 的短路语义。

## 八、运行库兼容性问题及处理

助教提供的 `libsysy_riscv.a` 由较新的 RISC-V 工具链构建，其 ISA 属性包含 `zmmul` 等扩展。旧版 SiFive GNU ld 2.35 在直接链接该二进制运行库时会报告：

```text
unknown z ISA extension `zmmul'
failed to merge target specific data
```

为了保持整条链路统一使用 SiFive GCC 10.2，本项目不替换链接器，而是使用助教提供的 `sylib.c` 重新构建本地运行库：

```bash
riscv64-unknown-elf-gcc   -O2 -mcmodel=medany -fno-pic   -I../../lib -c ../../lib/sylib.c   -o artifacts/sifive-runtime/sylib.o

riscv64-unknown-elf-ar rcs \
  artifacts/sifive-runtime/libsysy_riscv_sifive.a \
  artifacts/sifive-runtime/sylib.o
```

该归档文件和 SiFive 工具链具有一致的 RV64IMAFDC/LP64D 属性。

LLVM 后端生成的汇编首次包含 ISA 2.1 属性。`normalize_riscv_asm.py` 会将其规范化为 SiFive 2.35 支持的：

```text
rv64i2p0_m2p0_a2p0_f2p0_d2p0_c2p0
```

随后由 SiFive 汇编器生成目标文件，因此链接过程不产生 ISA 版本不匹配警告，也不需要替换链接器。
