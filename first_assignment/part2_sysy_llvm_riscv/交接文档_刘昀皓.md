## 三、程序语义

### 3.1 输入

从标准输入读取一个整数：

```text
n
```

### 3.2 常量

```text
BASE = 3
FACTOR = 2
```

SysY 常量可以在汇编实现中直接展开为立即数，不要求分配运行时存储。

### 3.3 `is_even(int x)`

当 `x % 2 == 0` 时返回 `1`，否则返回 `0`。

### 3.4 `gcd(int a, int b)`

使用欧几里得算法：

```text
while (b != 0) {
    t = a % b;
    a = b;
    b = t;
}
return a;
```

### 3.5 `main`

```text
n = getint()
i = 1
sum = 0

while (i <= n) {
    if (i == 4) {
        i = i + 1
        continue
    }

    if (i == 6) {
        break
    }

    if (i > 0 && is_even(i)) {
        sum = sum + i
    }

    i = i + 1
}

x = n + 3
y = n * 2 + 1
mixed = (x + y) * 2 - (x / 2) + (y % 3)
g = gcd(x, y)

putint(sum)
putch(10)
putint(mixed)
putch(10)
putint(g)
putch(10)

return 0
```

必须严格保持以下控制流：

- `i == 4` 时，先把 `i` 加一，再执行 `continue`。
- `i == 6` 时，执行 `break`，不再处理当前循环。
- `i > 0 && is_even(i)` 采用短路求值。
- `putch(10)` 表示输出换行符。
- 所有 `int` 运算按有符号 32 位整数语义处理。

## 五、RISC-V ABI 要求

目标工具链：

```text
riscv64-unknown-elf-gcc
```

目标：

```text
riscv64-unknown-elf
```

ABI：

```text
rv64imafdc/lp64d
```

编写汇编时至少注意：

1. 前 8 个整型参数依次放入 `a0` 至 `a7`。
2. 函数返回值放入 `a0`。
3. 调用其他函数前，如果需要跨调用保存值，应保存到栈或 callee-saved 寄存器。
4. 调用者应保存 `ra`，或者确保调用前已经正确保存。
5. 栈指针 `sp` 必须保持 16 字节对齐。
6. 调用运行库函数：

```text
getint
putint
putch
```

7. 32 位整数运算优先使用字指令：

```text
addw
subw
mulw
divw
remw
```

8. 比较前通常使用：

```text
sext.w
```

9. 函数调用使用：

```text
call symbol
```

10. 返回使用：

```text
ret
```

## 六、建议的汇编文件结构

```asm
    .text
    .globl is_even
is_even:
    # x 位于 a0，返回值位于 a0
    ret

    .globl gcd
gcd:
    # a 位于 a0，b 位于 a1，返回值位于 a0
    ret

    .globl main
main:
    # 主逻辑
    ret
```

是否需要 `.section`、`.type`、`.size` 和栈帧调试信息，可以根据助教要求选择。重点是生成正确机器码并保持 ABI。

## 七、汇编和链接

### 7.1 汇编

在目录：

```bash
cd /home/liuguoquan/Compiler-Principles-2026/first_assignment/part2_sysy_llvm_riscv
```

执行：

```bash
riscv64-unknown-elf-gcc \
  -c sysy_demo_asm.s \
  -o artifacts/sysy_demo_asm.o
```

也可以使用：

```bash
riscv64-unknown-elf-as \
  sysy_demo_asm.s \
  -o artifacts/sysy_demo_asm.o
```

### 7.2 链接

提供的 `libsysy_riscv.a` 使用了较新的 ISA 属性，原 SiFive GNU ld 2.35 无法合并其中的 `zmmul` 属性。

项目中已经准备了用户级 GNU binutils 2.42，位置为：

```text
$HOME/.local/opt/riscv-binutils-2.42/driver-bin
```

链接命令：

```bash
riscv64-unknown-elf-gcc \
  -B$HOME/.local/opt/riscv-binutils-2.42/driver-bin/ \
  artifacts/sysy_demo_asm.o \
  -o artifacts/sysy_demo_asm \
  -L../../lib -lsysy_riscv \
  -static -mcmodel=medany \
  -Wl,--no-relax,-Ttext=0x90000000
```

不要省略：

```text
-B$HOME/.local/opt/riscv-binutils-2.42/driver-bin/
```

否则旧链接器可能报：

```text
unknown z ISA extension `zmmul'
failed to merge target specific data
```

### 7.3 运行

```bash
qemu-riscv64 ./artifacts/sysy_demo_asm
```

输入可通过重定向提供：

```bash
qemu-riscv64 ./artifacts/sysy_demo_asm < tests/input_5.txt
```
